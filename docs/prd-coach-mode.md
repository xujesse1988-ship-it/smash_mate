# 教练模式 — 需求文档

**版本**: v1.0
**日期**: 2026-04-16
**作者**: PM

---

## 1. 背景与动机

当前教练用户使用 App 时，核心工作功能（课程管理、学员管理）入口较深：需要先进入「我的」页面，再从快捷链接列表中找到「课程管理」或「我的学员」。教练日常高频操作的路径过长，体验不佳。

**目标**：为教练用户提供「教练模式」，将底部导航直接替换为教练工作台，使课程管理和学员管理触手可及。

---

## 2. 用户旅程

**角色**: 已认证教练
**目标**: 快速进入教练工作台，管理课程和学员

**操作路径**:
1. 教练进入「设置」页面 → 看到「教练模式」开关
2. 开启教练模式 → 底部导航栏即时变化
3. 通过底部导航直接访问「课程」「学员」「我的」
4. 需要约球或找教练时 → 回到设置关闭教练模式

---

## 3. 功能说明

### 3.1 教练模式开关

- **入口位置**：设置页面，位于「教练资质（已认证）」下方
- **展示条件**：仅当 `isCoach === true` 时显示
- **控件形式**：Switch 开关，标签为「教练模式」
- **状态持久化**：开关状态存储在 localStorage，刷新/重启后保留
- **默认值**：关闭（普通模式）

### 3.2 底部导航栏变化

| 位置 | 普通模式 | 教练模式 |
|------|---------|---------|
| Tab 1 | 约球 → `/activities` | 课程 → `/my-courses` |
| Tab 2 | 找教练 → `/coaches` | 学员 → `/my-students` |
| Tab 3 | 我的 → `/users/:id` | 我的 → `/users/:id` |

- 教练模式下 Tab 1「课程」复用现有的课程管理页面（`MyCourseManagementPage`）
- 教练模式下 Tab 2「学员」复用现有的学员列表页面（`CoachStudentListPage`）
- Tab 3「我的」路由不变，但页面内容有差异（见 3.3）

### 3.3 教练模式下「我的」页面

教练模式下，「我的」页面的快捷链接列表精简为以下三项：

| 快捷链接 | 目标路由 |
|---------|---------|
| 教练资料 | `/profile/coach-edit` |
| 个人资料 | `/profile/edit` |
| 设置 | `/settings` |

- 用户信息区域（头像、昵称、战绩统计卡片）保持不变
- 隐藏的链接：我的活动、我的报名、课程管理、我的学员、战绩记录（这些功能已通过底部 Tab 或普通模式访问）

### 3.4 页面标题与导航调整

- 教练模式下，底部 Tab 对应的主页面需显示底部导航栏（即 `/my-courses` 和 `/my-students` 在教练模式下视为主页面）
- `/my-courses` 页面标题保持「课程管理」；页面顶部不显示返回按钮（因为它现在是 Tab 主页面）
- `/my-students` 页面标题保持「我的学员」；页面顶部不显示返回按钮（同上）
- 从 Tab 主页面进入的子页面（如学员详情、团课创建等）行为不变，仍显示返回按钮，返回到对应 Tab 主页面

### 3.5 默认首页

- 教练模式下，App 默认首页为 `/my-courses`（课程管理）
- 普通模式下保持 `/activities` 不变

## 4. 涉及的现有页面改动

| 文件 | 改动内容 |
|------|---------|
| `web/stores/auth-store.ts` | 新增 `coachMode` 状态 + localStorage 持久化 |
| `web/shared/components/BottomTabBar.tsx` | 根据 coachMode 状态切换 tabs 配置 |
| `web/shared/components/AppLayout.tsx` | 教练模式下将 `/my-courses`、`/my-students` 加入主页面列表；调整 `/my-courses` 的 TopBar 逻辑（不显示返回按钮） |
| `web/features/profile/pages/SettingsPage.tsx` | 新增教练模式 Switch 开关 |
| `web/features/profile/components/quick-link-list.tsx` | 接收 coachMode 参数，教练模式下精简链接列表 |
| `web/features/profile/pages/UserProfilePage.tsx` | 传递 coachMode 给 QuickLinkList |
| `web/routes.tsx` | 根路由 `/` 根据 coachMode 重定向到 `/my-courses` 或 `/activities` |

---

## 5. 不做的事（一期）

- 不新增页面 —— 全部复用现有页面
- 不改后端接口 —— 教练模式是纯前端状态
- 不做模式切换动画
- 教练模式下不隐藏约球/找教练的路由，用户仍可通过 URL 直接访问
- 不在 TopBar 显示「教练模式」标识

---

## 6. 验收标准

1. **开关可见性**：非教练用户在设置页面看不到「教练模式」开关
2. **开关功能**：教练用户开启后，底部导航栏立即切换为「课程 / 学员 / 我的」
3. **状态持久化**：刷新页面后教练模式状态保持不变
4. **课程 Tab**：点击「课程」进入课程管理页面，包含团课、私教时间、私教课、学员班四个子 Tab
5. **学员 Tab**：点击「学员」进入学员列表页面，支持搜索和标签筛选
6. **我的页面精简**：教练模式下快捷链接仅显示教练资料、个人资料、设置
7. **关闭还原**：关闭教练模式后，底部导航和我的页面恢复为普通模式
8. **子页面导航正常**：从课程/学员页面进入子页面后，返回按钮能正确返回
9. **默认首页**：教练模式下打开 App 默认进入课程管理页面
