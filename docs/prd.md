## 1. 项目概述

### 1.1 背景

羽毛球爱好者目前主要通过微信群组织约球和找教练，存在以下痛点：
- 信息分散在多个群聊中，难以检索和筛选合适的活动
- 无法记录和追踪比赛战绩，缺乏成就感和成长可视化
- 找教练依赖熟人推荐，信息不透明，缺少评价参考
- 活动变更（取消、改时间）时通知不及时，容易遗漏

### 1.2 目标用户

| 用户类型 | 特征描述 |
|----------|---------|
| 普通球友 | 一二线城市的羽毛球业余爱好者，有定期约球打球的需求 |
| 竞技选手 | 有竞技提升需求，关注战绩记录和教练指导 |
| 教练 | 具备羽毛球教学能力，希望通过平台招收学员、管理课程 |

**地域范围**：一二线城市
**推广策略**：先服务单个社区/球馆圈子，验证后向外扩展

### 1.3 核心价值

一站式解决羽毛球爱好者约球、找教练、记录战绩的需求，替代微信群的碎片化组织方式。

### 1.4 竞品/现状分析

| 维度 | 微信群（现状） | 本产品 |
|------|--------------|--------|
| 活动发布 | 群内文字发布，易被刷屏淹没 | 结构化发布，按时间/距离/空余筛选 |
| 信息检索 | 聊天记录中翻找，无法筛选 | 列表化展示，支持多维度筛选 |
| 找教练 | 依赖熟人推荐，信息不透明 | 教练入驻平台，有评价评分体系 |
| 战绩记录 | 无 | 支持多局比分记录，个人战绩汇总 |
| 活动变更通知 | 手动@群成员，易遗漏 | 系统自动通知所有参与者 |

## 2. 用户旅程

### 2.1 约球场景——普通球友发起约球

**角色**: 普通球友（已注册）
**目标**: 组织一场羽毛球活动
**前置条件**: 用户已登录

**操作路径**:
1. 用户进入首页 → 点击"发起约球"
2. 填写活动信息：选择球馆（输入关键词自动匹配附近球馆）、设定时间、限定人数 → 提交发布
3. 活动出现在约球列表中 → 其他用户可见
4. 有人加入时，发起人收到通知
5. 活动结束后，发起人或参与者可录入战绩

**异常路径**:
- 若发起人需要修改活动信息：编辑活动 → 系统自动通知所有已加入的参与者
- 若发起人取消活动：确认取消 → 系统自动通知所有参与者 → 活动标记为已取消

### 2.2 约球场景——球友加入活动

**角色**: 普通球友（已注册）
**目标**: 找到合适的活动并加入
**前置条件**: 用户已登录

**操作路径**:
1. 用户进入首页 → 浏览约球活动列表
2. 通过筛选条件（时间、距离、是否有空余）过滤活动
3. 点击某个活动 → 查看详情（球馆、时间、已报名人数/限定人数、发起人）
4. 点击"加入" → 加入成功，收到确认通知
5. 活动结束后可录入战绩

**异常路径**:
- 若活动人数已满：显示"已满"状态，"加入"按钮不可点击
- 若活动已被取消：详情页显示"已取消"，无法加入

### 2.3 约教练场景——报名团课

**角色**: 普通球友
**目标**: 找到教练并报名团课
**前置条件**: 用户已登录

**操作路径**:
1. 用户进入"找教练"页面 → 浏览教练列表
2. 点击教练头像/名字 → 进入教练主页（简介、擅长方向、评分、历史学员数、课程列表）
3. 在课程列表中选择一个团课 → 查看团课详情（时间、地点、已报名/限定人数、费用说明）
4. 点击"报名" → 报名成功，收到确认通知
5. 课程结束后可评价教练，可录入战绩

**异常路径**:
- 若团课已满：显示"已满"，"报名"按钮不可点击

### 2.4 约教练场景——预约私教课

**角色**: 普通球友
**目标**: 预约教练的私教课
**前置条件**: 用户已登录

**操作路径**:
1. 用户进入教练主页 → 查看教练的私教空闲时间表
2. 选择一个空闲时间段 → 点击"预约"
3. 预约成功 → 用户和教练都收到通知
4. 课程结束后可评价教练，可录入战绩

**异常路径**:
- 若该时间段已被其他人预约：显示"已约"，不可选择

### 2.5 教练场景——发布课程

**角色**: 教练
**目标**: 发布团课或设置私教空闲时间
**前置条件**: 用户已登录，且已开启教练角色

**操作路径**:
1. 教练进入"我的课程"管理页面
2. 发布团课：填写课程名称、时间、球馆、限定人数、费用说明 → 发布
3. 设置私教时间：在日历上勾选可用时间段 → 保存
4. 有学员报名/预约时收到通知

### 2.6 战绩录入场景

**角色**: 活动发起人或参与者
**目标**: 记录一场比赛的战绩
**前置条件**: 用户是某次约球活动/团课/私教课的参与者

**操作路径**:
1. 进入某次活动详情页 → 点击"录入战绩"
2. 选择或输入对战双方（平台用户从参与者中选择；非平台用户输入昵称）
3. 输入每局比分（支持多局，如 21:18, 21:15）
4. 提交 → 战绩记录在双方个人主页可见（平台用户）

## 3. 功能需求

### 3.1 用户管理（FA）

**描述**: 用户注册、登录、个人信息管理、角色管理。

**功能点**:
- [ ] FA-1: 用户注册（手机号+验证码注册，注册时可勾选是否为教练角色）
- [ ] FA-2: 用户登录
- [ ] FA-3: 个人资料编辑（头像、昵称、简介）
- [ ] FA-4: 教练角色开启/关闭（登录后可在设置中切换）
- [ ] FA-5: 个人主页（展示基本信息、历史战绩汇总——胜率、总场次）

**业务规则**:
1. 昵称不可为空，长度限制 2-20 个字符
2. 注册时勾选教练角色后，自动拥有教练功能权限
3. 未在注册时勾选教练的用户，登录后可在"设置"中开启教练角色
4. 教练角色可关闭，关闭后已发布的课程保持可见但标记为"教练已暂停"，不接受新报名
5. 一个账号同时具备普通用户和教练两种身份，不需要切换账号

**验收标准**:
1. [ ] 新用户注册后可登录并看到个人主页
2. [ ] 注册时勾选"我是教练"后，登录即可发布团课和私教课
3. [ ] 非教练用户在设置中开启教练角色后，立即获得发布课程的能力
4. [ ] 个人主页正确展示历史战绩汇总（胜场/负场/总场次/胜率）

### 3.2 约球（FB）

**描述**: 用户发起约球活动，其他用户浏览并加入。

**功能点**:
- [ ] FB-1: 发起约球活动（选择球馆、时间、限定人数）
- [ ] FB-2: 约球活动列表（支持筛选：时间、距离、是否有空余）
- [ ] FB-3: 活动详情页
- [ ] FB-4: 加入活动
- [ ] FB-5: 退出活动
- [ ] FB-6: 修改活动信息（仅发起人）
- [ ] FB-7: 取消活动（仅发起人）
- [ ] FB-8: 活动状态自动流转

**业务规则**:
1. 发起活动时必填：球馆、开始时间、限定人数（最少 2 人，最多 50 人）
2. 球馆通过输入关键词自动匹配系统中已有的球馆，不支持自由填写
3. 活动开始时间必须晚于当前时间
4. 活动状态：报名中 → 已满员 → 进行中 → 已结束 / 已取消
5. 人数达到上限后状态自动变为"已满员"，有人退出后回到"报名中"
6. 发起活动时必须设定结束时间，结束时间必须晚于开始时间
7. 活动开始时间到达后状态自动变为"进行中"，结束时间到达后变为"已结束"
8. 发起人修改活动信息后，系统通知所有已加入的参与者
9. 发起人取消活动后，系统通知所有参与者，活动标记为"已取消"
10. 已取消的活动不可恢复
11. 发起人自动算作活动的第一个参与者
12. 已开始或已结束的活动不可修改、不可加入

**验收标准**:
1. [ ] 用户填写球馆、时间、人数后可成功发起活动
2. [ ] 活动列表支持按时间排序、按距离排序、按是否有空余筛选
3. [ ] 点击"加入"后参与者人数 +1，加入者收到确认通知
4. [ ] 人数满员后"加入"按钮不可点击，显示"已满员"
5. [ ] 有人退出满员活动后，状态恢复为"报名中"
6. [ ] 发起人修改活动后，所有参与者收到变更通知
7. [ ] 发起人取消活动后，所有参与者收到取消通知

### 3.3 教练管理（FC）

**描述**: 教练入驻平台，管理个人主页，发布团课和私教课。

**功能点**:
- [ ] FC-1: 教练资料编辑（简介、擅长方向）
- [ ] FC-2: 教练主页展示（简介、擅长方向、评分、历史学员数、课程列表）
- [ ] FC-3: 发布团课（课程名称、时间、球馆、限定人数、费用说明）
- [ ] FC-4: 设置私教空闲时间（日历选择可用时间段）
- [ ] FC-5: 教练列表页（供普通用户浏览）
- [ ] FC-6: 团课管理（修改、取消）
- [ ] FC-7: 私教预约管理（查看、取消）

**业务规则**:
1. 只有教练角色的用户可以发布团课和设置私教时间
2. 团课必填：课程名称（最长 50 字符）、时间、球馆、限定人数（最少 2 人，最多 30 人）
3. 费用说明为文本描述字段，选填，一期不涉及在线支付
4. 私教时间段最小粒度为 1 小时
5. 同一时间段不可重复设置私教空闲
6. 教练取消团课时，系统通知所有已报名学员
7. 教练取消私教预约时，系统通知对应学员
8. 教练评分 = 所有评价的平均分（1-5 分）
9. 历史学员数 = 该教练所有团课和私教课的不重复参与人数
10. 教练列表默认按评分排序，支持按擅长方向筛选

**验收标准**:
1. [ ] 教练可成功发布团课，团课出现在教练主页和课程列表中
2. [ ] 教练可在日历上设置空闲时间段，学员可见并可预约
3. [ ] 学员报名团课后，教练收到通知，团课已报名人数 +1
4. [ ] 学员预约私教后，该时间段变为"已约"，不可被其他人选择
5. [ ] 教练取消团课后，所有已报名学员收到通知
6. [ ] 教练主页正确展示评分（所有评价的平均分）和历史学员数

### 3.4 战绩记录（FD）

**描述**: 记录约球活动、团课、私教课中的比赛比分，展示个人战绩汇总。

**功能点**:
- [ ] FD-1: 录入战绩（选择活动关联、对战双方、每局比分）
- [ ] FD-2: 查看活动的战绩列表
- [ ] FD-3: 个人战绩历史列表
- [ ] FD-4: 个人战绩汇总统计（胜场、负场、总场次、胜率）

**业务规则**:
1. 战绩必须关联到某次约球活动、团课或私教课，不支持独立录入
2. 活动的发起人和所有参与者均可录入该活动的战绩
3. 对战双方：平台用户从活动参与者中选择；非平台用户输入昵称
4. 非平台用户存储在临时用户表中，仅有昵称，仅在战绩中显示，不支持搜索查找
5. 每条战绩记录包含：对战双方、每局比分、日期（默认为活动日期）、场地（默认为活动场地）
6. 支持多局比分录入（如 21:18, 21:15, 21:19）
7. 单局比分为两个正整数
8. 一期不需要对方确认，录入即生效
9. 胜负判定：赢得多数局的一方为胜方（如 3 局 2 胜中赢 2 局者为胜）
10. 战绩汇总仅统计平台用户的数据，临时用户不生成汇总

**验收标准**:
1. [ ] 活动参与者可在活动详情页录入战绩，选择对战双方并输入每局比分
2. [ ] 非平台用户可通过输入昵称作为对战一方
3. [ ] 录入的战绩在双方（平台用户）的个人主页可见
4. [ ] 个人主页正确显示胜场、负场、总场次、胜率
5. [ ] 支持录入多局比分（至少 1 局，不限上限）

### 3.5 球馆管理（FE）

**描述**: 管理员维护球馆数据，供约球和教练发课时选择。

**功能点**:
- [ ] FE-1: 管理员添加支持的城市
- [ ] FE-2: 系统自动通过地图服务获取该城市的羽毛球球馆（名称、坐标）
- [ ] FE-3: 球馆数据每周定时自动更新
- [ ] FE-4: 球馆搜索（用户输入关键词，自动匹配最近的球馆）

**业务规则**:
1. 管理员添加城市后，系统自动调用地图服务查询该城市的羽毛球场馆
2. 球馆数据包含：球馆名称、详细地址、经纬度坐标
3. 每周定时更新已添加城市的球馆数据（新增球馆自动入库，已关闭球馆不自动删除，由管理员手动处理）
4. 用户输入球馆关键词时，按名称模糊匹配 + 距离排序返回结果；需要用户授权定位，若用户拒绝定位则仅按名称匹配排序
5. 球馆数据仅管理员可维护，普通用户和教练只能选择已有球馆

**验收标准**:
1. [ ] 管理员添加城市后，系统自动获取该城市的羽毛球球馆列表
2. [ ] 用户在发起约球/发布团课时输入球馆名称关键词，下拉展示匹配的球馆列表
3. [ ] 球馆数据每周自动更新，新增球馆可被搜索到

### 3.6 通知（FF）

**描述**: 系统在关键事件发生时向相关用户发送通知。

**功能点**:
- [ ] FF-1: 站内消息通知
- [ ] FF-2: 通知列表页（已读/未读）
- [ ] FF-3: 未读消息数角标

**业务规则**:
1. 以下事件触发通知：
   - 有人加入你发起的约球活动
   - 活动信息被发起人修改
   - 活动被发起人取消
   - 有学员报名你的团课
   - 有学员预约你的私教课
   - 教练取消了你报名的团课
   - 教练取消了你的私教预约
   - 你的课程收到新评价
2. 通知为站内消息，一期仅做站内通知，不做短信/邮件/微信推送
3. 通知分为已读和未读两种状态
4. 用户可标记单条通知为已读，或一键全部标记已读
5. 通知保留 90 天，过期自动清理

**验收标准**:
1. [ ] 上述所有事件触发时，相关用户收到站内通知
2. [ ] 未读通知在导航栏显示角标数字
3. [ ] 通知列表区分已读和未读，支持标记已读和一键全部已读

### 3.7 评价评分（FG）

**描述**: 学员对教练进行评价和评分。

**功能点**:
- [ ] FG-1: 提交评价（评分 + 文字评价）
- [ ] FG-2: 教练主页评价列表
- [ ] FG-3: 教练平均评分计算与展示

**业务规则**:
1. 只有实际参加过该教练团课或私教课的学员可以评价
2. 评分范围 1-5 分（整数）
3. 文字评价最长 500 个字符，可选填
4. 每个学员对同一个教练的同一次课程只能评价一次，不可修改，保证评价真实性
5. 教练主页的评分 = 所有评价的算术平均值，保留一位小数
6. 评价列表按时间倒序展示

**验收标准**:
1. [ ] 课程结束后学员可对教练提交 1-5 分的评分和文字评价
2. [ ] 未参加过该教练课程的用户无法提交评价
3. [ ] 教练主页的评分为所有评价的平均值
4. [ ] 评价列表按时间倒序展示

## 4. 跨模块业务流

### 4.1 约球活动全流程

**触发条件**: 用户发起约球活动
**参与模块**: 用户管理 → 约球 → 球馆管理 → 通知 → 战绩记录

**正常路径**:
1. 发起人创建活动 → 选择球馆（球馆管理提供搜索匹配）→ 活动发布成功
2. 其他用户加入 → 通知模块通知发起人
3. 活动到时间自动标记为进行中 → 结束后标记为已结束
4. 参与者录入战绩 → 战绩模块记录并更新双方个人统计

**异常处理**:
- 发起人取消活动 → 通知所有参与者 → 活动标记为已取消 → 不可录入战绩
- 发起人修改活动信息 → 通知所有参与者

**验收标准**:
1. [ ] 从发起到结束到战绩录入的全链路可走通
2. [ ] 活动取消后，相关通知送达所有参与者

### 4.2 约教练全流程（团课）

**触发条件**: 教练发布团课
**参与模块**: 教练管理 → 球馆管理 → 通知 → 评价评分 → 战绩记录

**正常路径**:
1. 教练发布团课 → 选择球馆 → 课程上线
2. 学员报名 → 通知教练
3. 课程结束后 → 学员可评价教练 + 录入战绩

**异常处理**:
- 教练取消团课 → 通知所有已报名学员 → 课程标记为已取消
- 团课已满员 → 后续学员无法报名

**验收标准**:
1. [ ] 从教练发课到学员报名到课后评价和战绩录入的全链路可走通

### 4.3 约教练全流程（私教）

**触发条件**: 教练设置私教空闲时间
**参与模块**: 教练管理 → 通知 → 评价评分 → 战绩记录

**正常路径**:
1. 教练设置空闲时间 → 时间段上线可见
2. 学员选择时间段预约 → 通知教练和学员
3. 课程结束后 → 学员可评价教练 + 录入战绩

**异常处理**:
- 教练取消预约 → 通知学员 → 时间段恢复为可预约
- 时间段冲突（被其他人先约）→ 提示学员该时间段已被预约

**验收标准**:
1. [ ] 从教练设置空闲到学员预约到课后评价和战绩录入的全链路可走通

### 4.4 教练角色变更联动

**触发条件**: 用户关闭教练角色
**参与模块**: 用户管理 → 教练管理 → 通知

**正常路径**:
1. 教练在设置中关闭教练角色
2. 该教练所有未开始的团课标记为"教练已暂停"，不接受新报名
3. 已有预约的私教课程保持不变（教练应自行处理）

**异常处理**:
- 已有学员报名的团课被暂停 → 通知已报名学员

### 5.2 操作路径

**底部导航结构**: 约球 | 找教练 | 我的

**核心路径**:
```
注册/登录 → 首页（约球列表）
                 ├→ 筛选活动 → 活动详情 → 加入活动
                 ├→ 发起约球 → 填写信息 → 发布成功
                 └→ 活动详情 → 录入战绩

找教练 → 教练列表 → 教练主页 ├→ 团课详情 → 报名
                              ├→ 私教时间 → 预约
                              └→ 评价列表 → 提交评价

我的 → 个人主页 ├→ 编辑资料
                 ├→ 战绩历史
                 ├→ 我的活动（发起的/参加的）
                 ├→ 我的课程（教练角色）
                 └→ 设置（教练角色开关）
```

### 5.3 交互要求

- 响应式布局，优先适配移动端浏览器，兼容桌面端
- 球馆输入框：输入时实时显示匹配结果下拉列表（debounce 300ms）
- 活动列表支持下拉刷新和上拉加载更多
- 通知角标实时更新（页面刷新时更新即可，一期不做 WebSocket 实时推送）

## 6. 非功能需求

- **性能**: 页面首次加载时间 ≤ 3 秒（4G 网络环境）；活动列表接口响应时间 ≤ 500ms
- **安全**: 用户密码加密存储；接口需做身份认证和权限校验
- **兼容性**: 支持主流移动端浏览器（Chrome、Safari、微信内置浏览器）；桌面端支持 Chrome、Edge
- **可用性**: 一期目标 99.5% 可用性（允许计划内维护窗口）

## 7. 成功指标

| 指标 | 目标值 | 衡量方式 | 统计周期 |
|------|--------|---------|---------|
| 注册用户数 | 首月 ≥ 100 | 注册数据统计 | 月 |
| 周活跃用户率 | ≥ 40% | 周内有登录行为的用户 / 总注册用户 | 周 |
| 约球活动创建数 | 首月 ≥ 50 | 活动创建统计 | 月 |
| 约球活动平均参与率 | ≥ 60% | 实际参与人数 / 限定人数 | 月 |
| 教练入驻数 | 首月 ≥ 5 | 开启教练角色的用户数 | 月 |
| 战绩录入率 | ≥ 30% | 有战绩记录的活动 / 已结束的活动 | 月 |

**关键数据埋点**:
- 用户注册完成事件（含是否勾选教练）
- 约球活动创建、加入、取消事件
- 团课/私教报名事件
- 战绩录入事件
- 教练评价提交事件
- 球馆搜索关键词和选择结果

- 社交功能（关注、动态）
