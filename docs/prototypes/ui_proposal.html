实施路线图

按优先级排列，P0 最高优先，先夯实 Design Token + 全局 Layout，再逐步推进各页面。

问题现状方案
无设计系统颜色硬编码 #00C853、#1890ff 等散落统一 CSS 变量 Token
样式方式全 inline style，难维护CSS 变量 + 全局 class
卡片层次弱仅 borderBottom 分隔独立圆角卡片 + 暗色背景
Loading/Error纯文字"加载中..."骨架屏 + 统一状态组件
底栏白底，无模糊效果毛玻璃 + 绿色激活态
P0
建立 CSS 变量 Design Token + 全局样式
在 index.css 中定义 :root 变量，替换所有 inline 硬编码色值。这是其他所有改动的前提。
