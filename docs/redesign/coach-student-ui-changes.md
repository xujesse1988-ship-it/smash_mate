# 统一学员管理 — 界面功能调整清单

> 本文只描述**用户肉眼能看到的界面/功能变化**，不涉及底层数据模型和接口。
> 数据模型和接口调整见 `coach-student-unified.md`。

## 一、导航菜单（个人主页 quick-link）

### 教练身份

**移除**
- ~~我的私教学员~~

**新增**
- **我的学员** → `/my-students`

**保留不变**
- 我的活动、我的报名、课程管理、教练资料、战绩记录、个人资料、设置

### 非教练身份
- 无变化，**不显示**"我的学员"菜单

---

## 二、新增页面

### 2.1 我的学员列表页（`/my-students`）

**页头**：BackButton + 标题"我的学员"（样式对齐其他列表页）

**顶部操作区**
- **搜索框**：昵称 / 手机号 / 手机号后 4 位（复用通用用户搜索）
- **"添加学员"按钮**：右上角，点击弹窗输入手机号；手机号未注册则 toast 提示"请学员先注册"

**筛选标签（Chip 行）**
- 全部
- 固定私教
- 团课学员
- 私教学员
- 学员班（点击后出现二级选择器，选择具体班）
- 教练自定义的标签（从 `StudentTag` 聚合出来的所有标签名）

**列表卡片**（每条一张卡）
- 头像 + 昵称
- 标签 chips（最多显示 3 个，溢出显示 "+N"）
- 首次成为学员的日期（例："2026-03 起"）
- 右箭头表示可点击

**空态**
- 有筛选条件：`暂无匹配的学员`
- 无筛选条件：`还没有学员`

**分页**
- 滚动加载 + "加载更多"按钮

---

### 2.2 学员详情页（`/my-students/:studentId`）

**页头**：BackButton + "学员详情"

**基本信息区**
- 头像、昵称
- 手机号后 4 位（例：`尾号 8921`）
- 首次成为学员时间
- 首次成为学员的来源（文案：`手动添加` / `上过团课` / `上过私教` / `学员班成员`）

**标签区**
- 显示所有派生标签和自定义标签（同一个 chip 样式，不区分）
- 可点击的"编辑标签"图标（铅笔）→ 弹窗可增删自定义标签（包括"固定私教"这个标签）
- 派生标签（团课学员/私教学员/学员班:XX）只读，无法删除；在弹窗里会灰化

**所属学员班区**（仅当学员在教练的某些班里时显示）
- 横向卡片列表，每张显示班名
- 点击跳转到学员班详情页

**历史课程区**
- 三类课程合并展示：团课 / 一次性私教 / 教练排的私教 / 学员班排课
- 按时间倒序
- 每条卡显示：课程标题（团课名/学员班名/"私教课"）+ 时间 + 球馆 + 状态
- 点击跳转到对应课程详情

**底部浮动操作按钮**
- **"给 TA 排课"**（主按钮）→ 跳转到私教排课表单（自动填充学员）

## 三、现有页面的变化

### 3.1 课程管理（`/my-courses`）

**三个 Tab 保持不变**：团课 / 私教时间 / 学员班

**"私教时间" Tab 的变化**

现有行为保留：
- 添加时间段
- 列表展示（时段/球馆/费用/状态）
- 已被预约的时段点进去看预约详情

**新增视觉元素**
- 状态徽章多一个 **`已过期`**（灰色）— 对应到期仍未被预约的时段
- 默认**只展示未来**的时段（过滤掉 `已过期` 和 `已完成`）
- 顶部加一个切换 toggle：`显示历史时段`（默认关闭）— 打开后显示过期/已完成的时段

**不变**
- "团课" Tab 完全不变
- "学员班" Tab 完全不变

---

### 3.2 学员班页面（`/my-student-classes` 及下属）

**不变**
- 班级列表页：仍然展示教练的所有学员班
- 班级详情页：班级信息、成员列表、排课列表、排课功能
- 班级学员档案页：笔记、出勤、标签

**唯一视觉差异**
- 班级学员档案页里的"标签"区显示的就是该学员在**全局**的自定义标签（和"我的学员"详情页的标签区是同一套）— 因为标签不再按"班"维度分开存储
- 这意味着：教练在班级档案里加的标签，去"我的学员"里也能看见；反之亦然

---

### 3.3 我的报名 / 我的课程（`/my-enrollments`）

**不变**
- 三类卡片展示：团课 / 私教 / 学员班排课
- 筛选、分页、卡片点击跳转

**细微变化**
- "私教"类卡片背后的数据来源合并了（一次性私教 + 教练排的固定私教课都在这里），但**用户视角看不出区别** — 都是"一节私教课"
- 卡片上可能增加一个小字标签区分 `我预约的` vs `教练排的`（待产品决定是否展示）

---

### 3.4 课程取消/退课按钮（所有相关页面）

涉及页面：
- 活动详情页的"退出活动"
- 团课详情页的"取消报名"
- 私教课详情页的"取消预约"
- 学员班排课详情页的"取消课程"

**变化**
- **新规则**：课程一旦进入 `进行中` 或 `已完成` 状态，取消/退课按钮**隐藏或置灰**
- 如果后端返回错误（并发场景），前端 toast 提示："课程已开始，不可退课"
- 已经过 `status === 'scheduled'` 校验通过的，行为和以前一致

---

### 3.5 教练主页（`/coaches/:id`，学员视角）

**不变**
- 教练资料、专长、评分
- "课程" Tab 展示团课列表
- "评价" Tab 展示评价
- 私教预约入口 → 跳到预约页

**细微变化**
- 学员预约页面（`/coaches/:id/private-lessons`）的时段列表里，**已过期的时段不再出现**
- 时段卡的字段展示不变

---

### 3.6 学员预约私教页（`PrivateLessonBookingPage`）

**不变**
- 时段列表
- 候选球馆选择
- 确认预约弹窗

**细微变化**
- 后端字段结构调整，但用户感知不到
- 过期时段被后端过滤，列表里直接不显示

## 四、删除的页面

**替代**：所有功能并入"我的学员"页面；固定私教身份变成一个可编辑的标签。

## 五、用户可能感知的"行为变化"

| 场景 | 原行为 | 新行为 |
|---|---|---|
| 学员 A 报了教练的团课，但教练从没主动加过他 | 教练看不到这个学员（除非在团课详情里翻） | 团课开始后，学员 A 自动出现在"我的学员"，带 `团课学员` 标签 |
| 教练想给学员 B 排私教课 | 必须先"加为固定私教"，然后进"我的私教学员"详情页排课 | 直接进"我的学员" → B → "给 TA 排课"；不强制加固定私教标签 |
| 教练想把学员 C 标记为固定私教 | 专门的"加为固定私教"按钮 | 在 C 的学员详情页，标签编辑弹窗里勾选"固定私教" |
| 学员 D 团课开始前 1 分钟想退课 | 允许 | 允许 |
| 学员 D 团课开始后想退课 | 允许（当前未限制） | **拒绝**，提示"课程已开始，不可退课" |
| 教练开了 10 个私教时段，3 天过去都没人约 | 时段一直留在列表里占空间 | 自动标记为 `已过期`，默认不展示；30 天后从 DB 清除 |

## 七、关键澄清

1. **"学员班"不会消失** — 它仍是课程管理里的一个 Tab，班级详情页仍有独立的成员管理界面
2. **"我的学员"是聚合视图** — 等于把所有渠道进来的学员（团课/私教/学员班/手动）用一张表聚合展示，不是替代学员班
3. **"固定私教"从按钮变标签** — 原来的"加为固定私教"独立按钮消失，改为学员详情页的标签编辑里勾选
4. **过期时段是新状态** — 课程管理"私教时间"Tab 里可能看到灰色的"已过期"徽章
