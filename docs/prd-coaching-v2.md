## 1. 项目概述

### 1.1 背景

一期上线后，教练功能仅支持发布团课和设置私教时间段，缺少以下能力：
- **教练资质无法验证**：任何用户勾选"我是教练"即可开始发课，学员无法判断教练是否专业
- **长期学员缺乏管理工具**：教练带固定学员班或长期私教学员时，没有排课、记录训练内容、跟踪学员进展的工具，只能靠微信群+纸笔记录
- **学员成长不可见**：训练笔记、打标签、学员间战绩等数据散落在各处，无法形成体系化的训练管理

### 1.2 目标用户

| 用户类型 | 需求 |
|----------|------|
| 教练 | 管理学员班和固定私教学员，排课、记录训练内容、做笔记、跟踪学员进展 |
| 学员 | 查看课程安排，被教练加入学员班或成为固定私教学员 |
| 管理员 | 审核教练资质，确保平台教练质量 |

### 1.3 核心价值

为教练提供一站式学员管理和训练记录工具，让教练能够专业化管理学员班和私教学员，同时通过资质审核提升平台教练的可信度。

### 1.4 竞品/现状分析

| 维度 | 现状（一期 + 微信） | 本次增强 |
|------|-------------------|---------|
| 教练资质 | 无审核，任何人可开启教练角色 | 上传证书/奖状，管理员审核通过后才能发课 |
| 学员班管理 | 微信群组织，信息散落 | 平台内创建学员班，统一排课、记录 |
| 训练记录 | 无 | 每节课可录入训练内容 |
| 学员笔记 | 教练自己用备忘录记 | 平台内按学员做笔记，关联到学员档案 |
| 学员标签 | 无 | 教练可给学员打标签（如"左手"、"进攻型"） |
| 私教管理 | 仅时间段预约，无长期管理 | 支持固定私教学员，长期排课和训练跟踪 |

## 2. 用户旅程

### 2.1 教练申请审核

**角色**: 用户（想成为教练）
**目标**: 提交教练资质审核并获得教练权限
**前置条件**: 用户已注册登录

**操作路径**:
1. 用户在设置中点击"申请成为教练" → 进入教练申请页面
2. 上传证书或奖状图片（至少 1 张，最多 5 张） → 填写简要说明 → 提交申请
3. 系统显示"审核中" → 管理员在后台审核
4. 审核通过 → 用户收到通知"教练资质审核已通过" → 自动获得教练功能权限
5. 审核不通过 → 用户收到通知"教练资质审核未通过：{原因}" → 可重新提交申请

**异常路径**:
- 若用户上传的图片格式不支持：提示"仅支持 JPG/PNG 格式"
- 若用户在审核中再次提交：提示"你已有一个审核中的申请"

### 2.2 教练创建和管理学员班

**角色**: 教练（已通过审核）
**目标**: 创建学员班，管理学员，安排课程
**前置条件**: 教练已通过资质审核

**操作路径**:
1. 教练进入"我的学员班"页面 → 点击"创建学员班"
2. 输入班级名称 → 创建成功
3. 在学员班中点击"添加学员" → 通过昵称或手机号搜索已注册用户 → 选择并添加 → 该用户收到通知"你已被加入学员班「{班级名称}」"
4. 点击"创建课程" → 填写日期、时间、球馆、训练内容 → 创建成功 → 所有学员收到上课通知
5. 课程创建后 → 教练可随时修改训练内容、随时新增笔记；课程开始后可录入学员间战绩

### 2.3 教练管理固定私教学员

**角色**: 教练（已通过审核）
**目标**: 添加固定私教学员，长期排课和训练管理
**前置条件**: 教练已通过资质审核

**操作路径**:
1. 教练进入"我的私教学员"页面 → 点击"添加学员"
2. 通过昵称或手机号搜索已注册用户 → 选择并添加 → 该用户收到通知
3. 点击进入学员详情 → 可查看该学员的所有课程、笔记、标签、战绩
4. 点击"创建课程" → 填写日期、时间、球馆、训练内容 → 创建成功 → 学员收到通知
5. 课程创建后 → 教练可随时修改训练内容、随时新增笔记；课程开始后可录入战绩（对手可以是任意平台用户）、打标签

### 2.4 管理员审核教练

**角色**: 管理员
**目标**: 审核教练提交的资质证书
**前置条件**: 管理员已登录后台

**操作路径**:
1. 管理员进入"教练审核"页面 → 查看待审核列表
2. 点击某个申请 → 查看证书/奖状图片和说明
3. 点击"通过" → 该用户获得教练权限，收到审核通过通知
4. 或点击"拒绝" → 填写拒绝原因 → 该用户收到审核拒绝通知

## 3. 功能需求

### 3.1 教练审核（GA）

**描述**: 教练资质审核功能。新申请的教练需上传证书/奖状，由管理员审核通过后才能使用教练功能。一期已存在的教练自动保留资格，无需审核。

**功能点**:
- [ ] GA-1: 教练申请（上传证书/奖状图片 + 简要说明）
- [ ] GA-2: 管理员审核教练申请（通过/拒绝 + 拒绝原因）
- [ ] GA-3: 教练审核状态展示（审核中/已通过/已拒绝）
- [ ] GA-4: 重新申请（被拒绝后可重新提交）
- [ ] GA-5: 管理员后台审核列表（待审核/已通过/已拒绝筛选）

**业务规则**:
1. 一期已注册的教练（数据库中 isCoach=true 的用户）自动标记为"已通过"，无需重新审核
2. 新用户申请教练角色时，必须上传至少 1 张证书/奖状图片，最多 5 张
3. 图片格式仅支持 JPG、PNG，单张大小不超过 5MB
4. 申请时可填写简要说明（选填，最多 200 字符），用于补充证书说明
5. 教练审核状态：未申请 → 审核中 → 已通过 / 已拒绝
6. 同一时间只能有一个待审核的申请，审核中不可重复提交
7. 被拒绝后可重新提交申请，重新进入"审核中"状态
8. 审核状态为"审核中"或"已拒绝"的用户不能使用教练功能（发布团课、设置私教、创建学员班等）
9. 审核通过后，用户的 isCoach 标记为 true，立即获得全部教练功能
10. 管理员审核时必须查看证书图片，通过时无需填写理由，拒绝时必须填写拒绝原因（最少 5 个字符）
11. 审核通过/拒绝后，系统自动通知申请人
12. 一期的"注册时勾选教练"和"设置中开启教练角色"入口改为"申请成为教练"，引导用户进入审核流程

**验收标准**:
1. [ ] 用户上传 1-5 张证书图片并提交后，状态变为"审核中"
2. [ ] 审核中不可重复提交申请，提示"你已有一个审核中的申请"
3. [ ] 上传非 JPG/PNG 格式的文件时提示格式错误
4. [ ] 上传超过 5MB 的图片时提示文件过大
5. [ ] 管理员在后台看到待审核列表，可查看证书图片
6. [ ] 管理员点击"通过"后，申请人收到通知，立即可使用教练功能
7. [ ] 管理员点击"拒绝"并填写原因后，申请人收到包含拒绝原因的通知
8. [ ] 被拒绝的用户可重新提交申请
9. [ ] 一期已有教练无需审核，自动保留教练资格
10. [ ] 审核中/已拒绝的用户无法发布团课、设置私教时间

### 3.2 学员班（GB）

**描述**: 教练可创建学员班，管理固定学员，逐次安排课程，记录训练内容和笔记，录入学员间战绩。

**功能点**:
- [ ] GB-1: 创建学员班（名称）
- [ ] GB-2: 编辑学员班名称
- [ ] GB-3: 删除学员班（需确认，会删除所有关联数据）
- [ ] GB-4: 添加学员（通过昵称或手机号搜索已注册用户）
- [ ] GB-5: 移除学员
- [ ] GB-6: 创建课程（日期、开始时间、结束时间、球馆）
- [ ] GB-7: 编辑课程
- [ ] GB-8: 取消课程
- [ ] GB-9: 录入课程训练内容
- [ ] GB-10: 录入课程笔记（每次新增一条）
- [ ] GB-11: 录入学员间战绩
- [ ] GB-12: 学员管理——对学员做笔记
- [ ] GB-13: 学员管理——给学员打标签
- [ ] GB-14: 学员班列表页（教练视角）
- [ ] GB-15: 学员班详情页（课程列表、学员列表）

**业务规则**:
1. 仅审核通过的教练可创建学员班
2. 教练可创建多个学员班，数量无上限
3. 班级名称不可为空，长度限制 2-30 个字符
4. 添加学员时，通过昵称或手机号（精确匹配手机号后 4 位或完整手机号，昵称模糊匹配）搜索已注册用户
5. 搜索结果展示匹配的用户列表（头像、昵称、手机号后 4 位），教练选择后添加
6. 只能添加已注册的平台用户，不支持添加非注册用户
7. 同一用户不可重复添加到同一学员班
8. 添加学员后，该用户收到通知"教练 {教练昵称} 将你加入了学员班「{班级名称}」"
9. 移除学员后，该用户收到通知"你已被移出学员班「{班级名称}」"
10. 创建课程必填：日期、开始时间、结束时间、球馆
11. 课程的开始时间必须晚于当前时间，结束时间必须晚于开始时间
12. 球馆从系统已有球馆中选择（复用一期球馆搜索功能）
13. 课程创建后，学员班内所有学员收到上课通知
14. 课程状态：未开始 → 进行中 → 已结束 / 已取消
15. 课程开始时间到达后自动变为"进行中"，结束时间到达后变为"已结束"
16. 教练可编辑未开始的课程信息，编辑后通知所有学员
17. 教练可取消未开始的课程，取消后通知所有学员
18. 已开始或已结束的课程不可编辑或取消
19. 训练内容为纯文本字段，最多 2000 字符；创建课程时即可填写（选填），创建后随时可修改
20. 课程笔记：每次录入都是一条新笔记（追加模式，不修改之前的笔记）
21. 单条笔记最多 500 字符，不可为空
22. 笔记按录入时间倒序展示，仅教练可见
23. 学员间战绩录入：课程状态为"进行中"或"已结束"时均可录入；复用一期的战绩录入逻辑（选择比赛类型、对战双方、每局比分），但参与者限定为本学员班的学员
24. 未开始的课程不可录入战绩
25. 战绩关联到具体的课程（sourceType='class_lesson'）
25. 学员笔记（GB-12）：教练可针对学员班中的某个学员写笔记，每次新增一条，仅教练可见
26. 学员标签（GB-13）：教练可给学员打标签（自由文本标签），如"左手"、"进攻型"、"需加强步法"
27. 标签为自由输入，单个标签最多 20 字符
28. 同一学员在同一学员班中最多 10 个标签
29. 笔记和标签仅教练自己可见，学员看不到
30. 删除学员班时需二次确认，确认后删除班级及其下所有课程、笔记、标签数据；已录入的战绩不删除（战绩为独立数据）

**验收标准**:
1. [ ] 教练可创建学员班，输入名称后创建成功
2. [ ] 教练通过昵称或手机号搜索到已注册用户并添加为学员
3. [ ] 重复添加同一学员时提示"该学员已在班级中"
4. [ ] 添加/移除学员后，对应用户收到通知
5. [ ] 教练创建课程后，所有学员收到上课通知
6. [ ] 课程状态按时间自动流转（未开始→进行中→已结束）
7. [ ] 教练可编辑未开始的课程，编辑后学员收到变更通知
8. [ ] 教练取消课程后，学员收到取消通知
9. [ ] 已开始的课程不可编辑或取消
10. [ ] 创建课程时可填写训练内容，创建后可随时修改（最多 2000 字符）
11. [ ] 教练可随时为课程新增笔记，每次新增一条，按时间倒序展示
12. [ ] 课程进行中或已结束时可录入学员间战绩，未开始时不可录入
13. [ ] 战绩参与者限定为本班学员
13. [ ] 教练可对学员做笔记，笔记仅教练可见
14. [ ] 教练可给学员打标签，最多 10 个，单个最多 20 字符
15. [ ] 删除学员班时需确认，确认后班级和关联数据被删除，战绩保留
16. [ ] 学员无法看到教练写的笔记和标签

### 3.3 固定私教学员（GC）

**描述**: 教练可添加固定私教学员（已注册用户），逐次安排一对一课程，记录训练内容和笔记，录入战绩，给学员打标签。

**功能点**:
- [ ] GC-1: 添加固定私教学员（通过昵称或手机号搜索已注册用户）
- [ ] GC-2: 移除固定私教学员
- [ ] GC-3: 创建私教课程（日期、开始时间、结束时间、球馆）
- [ ] GC-4: 编辑私教课程
- [ ] GC-5: 取消私教课程
- [ ] GC-6: 录入课程训练内容
- [ ] GC-7: 录入课程笔记（每次新增一条）
- [ ] GC-8: 录入战绩（对手可以是任意平台用户）
- [ ] GC-9: 对学员做笔记
- [ ] GC-10: 给学员打标签
- [ ] GC-11: 固定私教学员列表页
- [ ] GC-12: 学员详情页（课程历史、笔记、标签、战绩）

**业务规则**:
1. 仅审核通过的教练可添加固定私教学员
2. 教练可添加多个固定私教学员，数量无上限
3. 添加方式与学员班相同：通过昵称或手机号搜索已注册用户
4. 同一用户不可被同一教练重复添加为固定私教学员
5. 添加后，该用户收到通知"教练 {教练昵称} 将你添加为固定私教学员"
6. 移除后，该用户收到通知"教练 {教练昵称} 已将你从固定私教学员中移除"
7. 创建课程必填：日期、开始时间、结束时间、球馆
8. 课程规则与学员班课程一致（时间校验、状态流转、编辑/取消限制）
9. 课程创建后，学员收到上课通知
10. 训练内容录入规则与学员班一致（纯文本，最多 2000 字符；创建课程时即可填写，之后随时可修改）
11. 笔记录入规则与学员班一致（追加模式，单条最多 500 字符，仅教练可见，随时可录入）
12. 战绩录入：课程状态为"进行中"或"已结束"时均可录入；复用一期战绩逻辑，但对战双方可以是任意平台用户（不限于本私教关系内的人）
13. 未开始的课程不可录入战绩
14. 战绩关联到具体的私教课程（sourceType='private_lesson_v2'）
14. 学员笔记和标签规则与学员班一致（仅教练可见，标签最多 10 个）
15. 移除固定私教学员时需确认，移除后课程历史、笔记、标签数据保留（不删除）；教练仍可查看历史数据，但不能为该学员创建新课程

**验收标准**:
1. [ ] 教练可通过昵称或手机号搜索并添加固定私教学员
2. [ ] 重复添加同一学员时提示"该学员已是你的固定私教学员"
3. [ ] 添加/移除学员后，对应用户收到通知
4. [ ] 教练可为学员创建一对一课程，学员收到上课通知
5. [ ] 课程状态按时间自动流转
6. [ ] 教练可编辑/取消未开始的课程，学员收到通知
7. [ ] 教练可录入训练内容和笔记
8. [ ] 教练可录入战绩，对手可选择任意平台用户
9. [ ] 教练可对学员做笔记和打标签，学员不可见
10. [ ] 移除学员后历史数据保留，教练仍可查看
11. [ ] 移除学员后不能为该学员创建新课程

## 4. 跨模块业务流

### 4.1 教练申请审核流程

**触发条件**: 用户提交教练申请
**参与模块**: 用户管理(FA) → 教练审核(GA) → 通知(FF)

**正常路径**:
1. 用户上传证书图片 + 说明，提交申请 → 状态变为"审核中"
2. 管理员在 admin 后台查看申请，审核证书
3. 管理员点击"通过" → 用户 isCoach=true → 通知模块发送审核通过通知
4. 用户收到通知 → 可使用全部教练功能（发布团课、创建学员班、添加私教学员等）

**异常处理**:
- 管理员拒绝：填写拒绝原因 → 通知用户 → 用户可修改后重新提交
- 通知发送失败：不阻塞审核结果，记录 error 日志

**验收标准**:
1. [ ] 用户提交申请后管理员能在后台看到
2. [ ] 审核通过后用户立即能发布课程
3. [ ] 审核拒绝后用户收到包含原因的通知

### 4.2 学员班课程与战绩流程

**触发条件**: 教练为学员班创建课程
**参与模块**: 学员班(GB) → 通知(FF) → 战绩记录(FD)

**正常路径**:
1. 教练创建课程 → 通知模块通知所有学员
2. 课程按时自动流转为"进行中" → "已结束"
3. 课程结束后，教练录入训练内容 / 笔记 / 学员间战绩
4. 战绩记录关联到课程，计入相关学员的个人战绩汇总

**异常处理**:
- 教练取消课程：通知所有学员，课程标记为"已取消"
- 通知发送失败：不阻塞主流程

**验收标准**:
1. [ ] 学员班课程中录入的战绩正确计入学员的个人战绩汇总

### 4.3 固定私教课程与战绩流程

**触发条件**: 教练为固定私教学员创建课程
**参与模块**: 固定私教(GC) → 通知(FF) → 战绩记录(FD)

**正常路径**:
1. 教练创建课程 → 通知学员
2. 课程结束后，教练录入训练内容 / 笔记 / 战绩（对手可以是任意用户）
3. 战绩关联到私教课程，计入相关用户的个人战绩汇总

**异常处理**:
- 同 4.2

**验收标准**:
1. [ ] 私教课程中录入的战绩正确计入双方用户的个人战绩汇总

## 7. 成功指标

| 指标 | 目标值 | 衡量方式 | 统计周期 |
|------|--------|---------|---------|
| 教练审核通过率 | > 70% | 通过数 / 总申请数 | 上线后 30 天 |
| 学员班创建数 | > 20 | 数据统计 | 上线后 30 天 |
| 课程创建频率 | 平均每个活跃教练每周 > 2 节 | 数据统计 | 上线后 30 天 |
| 训练内容录入率 | > 50% 的课程有训练内容 | 有训练内容的课程 / 总课程 | 上线后 60 天 |

**关键数据埋点**:
- 教练申请提交事件
- 学员班创建事件
- 课程创建事件（区分学员班/私教）
- 训练内容录入事件
- 笔记录入事件
- 战绩录入事件（区分来源）

## 8. 不在范围内

- 在线支付（课程费用仍为线下协商）
- 学员主动申请加入学员班（本期仅教练主动添加）
- 学员退出学员班（本期仅教练移除）
- 课程签到/打卡功能
- 训练内容的富文本编辑（本期仅纯文本）
- 学员成长报告/数据分析（后续迭代）
- 教练之间共享学员数据
- 课程评价（本期学员班/固定私教课程不支持评价，一期团课/预约私教的评价功能不变）
